Agente de código · hecho en el Caribe

Cógela suave. El código sale.

Un agente de código en tu terminal. Lee, busca, edita y corre comandos en tu proyecto, con tu permiso.

$ npm install -g quillami-code
Primeros pasos

Node 22 o más nuevo · licencia MIT · cientos de modelos con una sola key de OpenRouter

Le das la tarea. Él la termina.

Quillami elige la herramienta, te pide permiso cuando va a cambiar algo, mira el resultado y sigue hasta terminar. Ctrl+C cancela el turno, no la sesión.

  1. tarea

    Escribes lo que quieres, con tus palabras. También en una sola línea: quillami "explica este archivo".

  2. tools

    read, grep, glob y ls para mirar. write, edit, bash y web_fetch para actuar.

  3. permiso

    Todo lo que cambia algo pregunta primero, con el diff a la vista. Sí, no, o sí por el resto de la sesión.

  4. repite

    Lee la salida, corrige y vuelve a intentar. Hasta 20 vueltas por turno.

Modo auto

El más barato que cumple.

En cada mensaje, Jev (de TypeSafe) mide qué tan difícil es la tarea y Quillami usa el modelo más barato que la resuelve bien. Una pregunta rápida no paga precio de Opus.

Modelos de auto con OpenRouter. Precio en dólares por millón de tokens, entrada / salida.
DificultadModeloPrecioPara qué
TrivialDeepSeek V4.1 Flash$0.03 / $0.50Una pregunta corta, un solo paso
EstándarMiMo V2.6 Pro$0.435 / $0.87Programación normal en el repo
DifícilClaude Sonnet 5.5$2 / $10Diseño, muchos archivos, debugging profundo
Muy difícilClaude Opus 5.5$4 / $20Arquitectura de un sistema, bug sutil entre módulos

Con una key gratis de Artificial Analysis, auto elige entre todo el catálogo de OpenRouter según benchmarks.

Sin key de Jev, usa MiMo V2.6 Pro en todos los mensajes. Con key de Anthropic, usa Haiku, Sonnet y Opus directos.

/usage te dice cuánto gastaste y cuánto te ahorraste frente a usar Claude Sonnet siempre.

Permisos

Ves el diff antes de aprobar.

write y edit te muestran lo que sale y lo que entra antes de tocar el archivo. Eliges con las flechas y Enter, o directo con s, n o a. Esc es no.

  • Jev aprueba solo los comandos inofensivos y frena los de riesgo alto.
  • “No preguntes más” vale solo para esa herramienta: aprobar bash no aprueba write.
  • En modo plan solo lee y termina con un plan. Nada se toca.

Lo que trae.

Lo necesario para trabajar en un repo de verdad, sin configurar nada más que tus keys.

  • /skills

    Skills

    Usa las skills que ya tienes en .claude/skills o .agents/skills. Carga la que aplica, o la fuerzas con /nombre.

  • /model

    OpenRouter

    Cientos de modelos con una sola key. /model abre la lista y buscas escribiendo.

  • /mcp

    MCP

    Conecta servidores por stdio o HTTP en ~/.quillami/mcp.json.

  • quillami -c

    Sesiones

    Retoma la última conversación del repo. /sessions lista las demás.

  • /mode

    Modos

    agent pregunta, plan solo lee y propone, yolo aprueba solo. La lista negra y Jev siguen activos.

  • QUILLAMI.md

    Memoria

    QUILLAMI.md o AGENTS.md para el repo. ~/.quillami para lo que aprende de ti.

  • web_fetch

    Web segura

    Lee páginas públicas. Bloquea localhost, redes privadas y redirecciones hacia ellas.

  • Ctrl+C

    Cancela sin miedo

    Corta el turno, no la sesión. /undo deshace los cambios del último turno.

Instálalo.

$ npm install -g quillami-code

  1. Instala con npm. Necesitas Node 22 o más nuevo.

  2. Corre quillami en tu proyecto. La primera vez marcas tus keys con la barra espaciadora: OpenRouter y Jev son las recomendadas.

  3. Escribe la tarea. Quillami te pregunta antes de tocar algo.

Consigue tus keys

Necesitas al menos una key de modelo: OpenRouter o Anthropic. Quillami te las pide la primera vez y las guarda en ~/.quillami/.env.

  • OpenRouter

    Recomendada

    Cientos de modelos con una sola key. Con esta ya puedes trabajar.

    OPENROUTER_API_KEY
  • Jev (TypeSafe)

    Recomendada

    Elige el modelo para cada mensaje y aprueba solo los comandos inofensivos.

    TYPESAFE_API_KEY
  • Anthropic

    Opcional

    Claude directo, sin pasar por OpenRouter.

    ANTHROPIC_API_KEY
  • Artificial Analysis

    Opcional · gratis

    Con OpenRouter y Jev, el modo auto elige según benchmarks.

    ARTIFICIAL_ANALYSIS_API_KEY
